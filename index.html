Enterprise Backup

Enterprise Backup is a private, single-user backup tool maintained by the owner of the GitHub account stopbeinglogical. It uses restic to encrypt local files and rclone to store encrypted backup snapshots in the owner's Google Drive.

Google authorization is used only to access backup files created by this application, using the drive.file permission. This tool is not offered as a public service and does not accept registrations.

This website contains information about the tool. It does not contain backups, credentials, or a login form.
