Enterprise Backup privacy policy

Effective October 16, 2026. Enterprise Backup is a private tool operated by the owner of the GitHub account stopbeinglogical for their own files and Google account.

Data and permissions

The tool uses Google OAuth and the drive.file permission to create and access encrypted backup repository files in the owner's Google Drive. Restic encrypts file contents, names, and snapshot metadata before upload. Google can observe stored object sizes and access activity.

Use and storage

Google account access is used solely for backup and explicitly supervised recovery. OAuth credentials and the encryption password are stored privately on the owner's computer, outside the working files and Git repositories. The owner is responsible for keeping an independent private recovery copy of the encryption password. Credentials and backup contents are not published on this website.

Sharing

The tool does not sell data, use it for advertising, or provide it for AI model training. Encrypted repository objects are transmitted to Google Drive to provide backup storage. Google processes that storage under its own policies. This static information site is hosted by GitHub Pages; GitHub may process visitor connection information under its own privacy policies. The site contains no added analytics, tracking scripts, or forms.

Retention and control

Backup snapshots remain until the owner explicitly authorizes removal. Historical pruning is disabled during initial recovery validation. The owner can revoke OAuth access through their Google account and can request or perform deletion of their backup repository. Revoking access does not automatically delete stored backups.

Contact

The owner maintains this tool through github.com/stopbeinglogical. Contact the maintainer through the public information on that profile; never include credentials or backup contents in public communications.
